## Progress Week 10 - Project Setup
Melakukan setup awal project aplikasi SisaBisa menggunakan Kotlin dan Jetpack Compose. Tahap ini mencakup konfigurasi dependency, pengaturan resource aplikasi, serta pembuatan tema dasar untuk mendukung pengembangan antarmuka
### Pekerjaan yang telah dilakukan : 
a.Setup project Android menggunakan Kotlin dan Jetpack Compose.
b.Konfigurasi dependency pada app/build.gradle.kts.
c.Mengatur versi library menggunakan gradle/libs.versions.toml.
d.Membuat colors.xml untuk konfigurasi warna aplikasi.
e.Membuat strings.xml untuk menyimpan teks aplikasi.
f.Membuat dimens.xml untuk mengatur ukuran dan spacing.
g.Membuat Theme.kt untuk konfigurasi tema Material 3.
h.Membuat Type.kt untuk konfigurasi tipografi.
